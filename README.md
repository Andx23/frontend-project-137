# RSS Reader

## Descripción

Aplicación web para agregar fuentes RSS y consultar sus publicaciones desde un solo lugar.

## Tecnologías

- HTML
- CSS
- JavaScript
- Bootstrap
- Vite

## Desarrollo local

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

## Comprobaciones

Ejecuta el linter:

```bash
npm run lint
```

Genera la versión de producción:

```bash
npm run build
```
